About SmartScan

SmartScan is a document scanning application built using Python and OpenCV. It detects document boundaries, corrects perspective distortion, and enhances readability to convert ordinary photographs into clean digital scans.

Technologies Used:
Python OpenCV NumPy Flask HTML CSS JavaScript
